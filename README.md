# Ava Desktop downloads

This repository hosts compiled Ava Desktop installers, checksums, and the signed update feed. It does not contain the application source repository.

[Download Ava 0.3.1 (build 7)](https://github.com/Zorcon40/ava-releases/releases/tag/v0.3.1-b7)

Supports Apple Silicon and Intel Macs running macOS 13 or later. The app chooses enhanced or lightweight voice setup for the Mac. This is a personal beta, locally signed and not Apple-notarized. Drag Ava to Applications, eject the disk image, and follow the included installation instructions. Physical Ventura testing is still in progress.

Installed copies check for signed updates hourly when idle. You can also check manually in Ava Settings. Installation preserves local setup and data.

Bug reports: use Report a problem in Ava to preview and save diagnostics or open the [private report inbox](https://github.com/Zorcon40/ava-feedback/issues). Access requires the owner account or an explicit invitation; reports are not public and are not sent automatically.
