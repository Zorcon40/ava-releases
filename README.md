# Ava for Mac

[Download Ava build 23](https://github.com/Zorcon40/ava-releases/releases/tag/v0.3.1-b23)

Universal beta for Apple Silicon and Intel Macs running macOS 13 or later. Open the DMG, drag Ava into Applications, then open Ava from Applications and follow guided setup.

Build 23 makes image requests open actual image-search results in your default browser, including from existing conversations. It includes Ava’s local voice and compatible components, guided permissions and connections, clearer installation, and improved long-message dictation. Updates preserve settings, history and memory.

**Build 7 users:** manually download and replace Ava once. That build has an updater startup bug. Later builds use the signed in-app update feed.

This locally signed beta is not Apple-notarized. See the release notes for macOS approval guidance, data handling and remaining validation limits.

This repository contains compiled downloads, checksums, release notes and the signed update feed only. Source code remains private.
